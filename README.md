# 🕒 Relógio Digital

## 📖 Sobre o Projeto

Este projeto consiste no desenvolvimento de um **Relógio Digital** utilizando **HTML**, **CSS** e **JavaScript**.

A aplicação exibe a hora atual em tempo real, atualizando automaticamente segundos, minutos e horas sem a necessidade de recarregar a página. O projeto foi desenvolvido com o objetivo de praticar manipulação de datas e horários, atualização dinâmica de elementos e estilização de interfaces web.

---

## 🎯 Objetivos

* Praticar os fundamentos do JavaScript.
* Trabalhar com objetos de data e hora.
* Atualizar elementos da página em tempo real.
* Manipular o DOM dinamicamente.
* Desenvolver interfaces modernas utilizando HTML e CSS.
* Compreender o funcionamento de funções temporizadas.
